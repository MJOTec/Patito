
Cómo ejecutar el compilador
Abre el archivo testSemantica.py.
Selecciona uno de los códigos de prueba o agrega tu propio programa Patito en la variable correspondiente.
Ejecuta testSemantica.py para compilar el programa.
Si el código es válido, se generará el archivo program.obj con los cuádruplos y estructuras de memoria.
Si hay errores sintácticos o semánticos, se mostrarán en consola.

Cómo ejecutar la Máquina Virtual
Una vez generado program.obj, abre el archivo VM.py.
Ejecuta VM.py.

La máquina virtual leerá program.obj y mostrará en consola el resultado del programa compilado.
